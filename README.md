# SecureFace-RX Web

라즈베리파이·AI HAT+ 없이 **노트북 브라우저만으로** 돌아가는 SecureFace-RX 웹 버전입니다.
노트북 카메라 영상에서 얼굴을 찾아 화면에 그리기 전에 가우시안 블러로 가리고, 등록자를 알아보며,
녹화한 얼굴을 집단별 키로 암호화해 두었다가 해당 키로 그 집단 얼굴만 복원합니다.

- 모든 처리는 브라우저 안에서 합니다. 카메라 영상은 서버로 전송되지 않습니다.
- 빌드 과정이 없는 정적 사이트(HTML + JavaScript 모듈)라 Vercel에 그대로 올릴 수 있습니다.

## 페이지

| 페이지 | 하는 일 |
|---|---|
| `index.html` 실시간 모니터 | 카메라 → 얼굴 탐지·인식 → 가우시안 블러, 허가자/비허가자 표시, 비허가자 경고 팝업, 감지 이력, 녹화 |
| `register.html` 얼굴 등록 | 정면 → 한쪽 → 반대쪽으로 고개를 돌리며 각도별 얼굴 수치 저장 (사진은 저장 안 함) |
| `restore.html` 복원 | 처음 한 번 복원 키 설정, 녹화 목록·블러 영상 재생, 집단 키로 그 집단 얼굴만 복원 |

## 구성

- 얼굴 탐지: MediaPipe Face Detector (BlazeFace short-range, CPU/WASM). 카메라 가까이(약 2m 이내) 얼굴용.
- 얼굴 인식: face-api.js (@vladmandic/face-api, MIT) 128차원 얼굴 벡터, 거리 0.5 미만이면 같은 사람.
  최근 3번 중 2번 같은 사람이어야 확정합니다(그 전에는 "확인 중").
- 블러: 얼굴 크기에 비례하는 가우시안 블러(canvas filter). 지원하지 않는 브라우저는 축소·확대 방식으로 대신합니다.
- 모델과 실행 파일은 실행할 때 CDN(jsdelivr, Google)에서 받아옵니다.
- 저장: 등록자, 감지 이력, 복원 키, 녹화는 모두 이 브라우저(IndexedDB)에만 저장합니다. 다른 브라우저·PC와 공유되지 않습니다.

## 녹화와 집단별 복원

라즈베리파이 버전과 같은 세 집단으로 얼굴을 나눠 암호화합니다.

| 키 | 복원되는 얼굴 |
|---|---|
| 외부인 | 등록되지 않은 얼굴 |
| 내부인 | 등록자로 인식된 얼굴 |
| 전체 | 모든 얼굴 (인식 확정 전 "확인 중"이던 얼굴은 전체 키로만) |

- 카메라가 켜져 있으면 초당 10장, 30초 단위로 녹화합니다. 블러된 프레임과, 얼굴마다 그 집단 키로 암호화한 원본 얼굴을 저장합니다.
- 키마다 RSA-OAEP 키 쌍을 만들어 공개키로 녹화하고(녹화하는 쪽은 열 수 없음), 개인키는 그 키 비밀번호로 잠가 둡니다.
  녹화 묶음마다 집단별 AES-256-GCM 데이터 키를 새로 만듭니다.
- 녹화는 최근 20묶음(약 10분)만 남기고 오래된 것부터 지웁니다.
- 복원 키는 처음 한 번 정하며 잊으면 그 집단 얼굴은 복원할 수 없습니다. 키를 정하기 전에는 녹화하지 않습니다.

## 로컬에서 실행

카메라는 `https` 주소나 `localhost`에서만 쓸 수 있습니다.

```bash
python -m http.server 5173 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:5173` 을 엽니다.

## Vercel 배포

빌드 설정은 필요 없습니다(Framework Preset: Other).

- GitHub 저장소를 Vercel 대시보드에서 **Add New → Project → Import**
- 또는 이 폴더에서 `npx vercel` (처음 한 번 로그인 필요)

## 진행 단계

1. [x] 카메라 → 얼굴 탐지 → 실시간 가우시안 블러 (탐지 누락 시 0.8초 동안 계속 가림)
2. [x] 얼굴 등록(별도 페이지, 각도별)·인식, 등록자 관리, 비허가자 경고 팝업, 감지 이력
3. [x] 30초 단위 녹화, 집단별 암호화, 복원 페이지(외부인·내부인·전체 키)
4. [ ] 시간·층 출입 통제
